# שרון בן אהרון | מאמנת הוליסטית רגשית

דף אישי פשוט בקובץ אחד (`index.html`), בעברית ומימין לשמאל, עם תמיכה במצב כהה.

## איך רואים אותו

פותחים את `index.html` בדפדפן. זהו.

## איך מפרסמים אותו

1. ב-GitHub נכנסים ל-Settings של הריפו ואז ל-Pages.
2. תחת Branch בוחרים `main` ואז Save.
3. אחרי דקה-שתיים הדף יעלה בכתובת `https://שם-משתמש.github.io/שם-הריפו`.

## מה לערוך

כל הטקסטים נמצאים ישירות ב-`index.html` וקל לערוך אותם.
